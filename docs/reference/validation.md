## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 类写好了却不工作 | 服务端导入链、block_name、@RegisterMachine、方块实体与 tick 组件 |
| MiniJEI 有分类没机器配方 | 命名空间只负责分类；公共配方集合是否两端加载 |
| 能加工但打不开配方页 | recipe_icon_id、SetRenderer、render_ui_def_name 及布局槽名 |
| 界面找不到坐标 | 代理是否使用前置 ToolDelta 注册器，ClientBlockUseEvent 是否收到方块点击 |
| 流体管道很快但流量很低 | 网络容量是否至少覆盖周期预算、源是否有液、目标是否能接收 |
| 管道连接外观异常 | 六面 connection/cable_io 状态、骨骼条件、原 JSON permutations 是否完整 |
| 独立管网重复运输 | 是否误保留内置流体管道标签、是否有多个 LogicModule 命中 |
| 只在重进后丢状态 | long、混合类型列表、只改嵌套缓存未重新赋值，或读缓存误当成落盘成功 |
| 旧核能示例报 PIPE 不存在 | 当前仅有 ITEM_PIPE/FLUID_PIPE/WIRE；独立类型使用自己的命名空间字符串 |
