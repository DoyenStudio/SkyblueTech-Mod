# 工业离心机

在机件加工台用殷钢扳手和殷钢钳加工 16 次，获得下层方块 `skybluetech:industrial_centrifuge_downside`。放置时上方预留一格，转子会自动组装。两层均可打开主面板。电线、物品管和流体管接下层，热源或导热块接下层底面。基础电量缓冲为 32,000 RF。

| 钢板 | 电动马达 | 钢板 |
| --- | --- | --- |
| 钢制流体储罐 | 机器框架 | 钢制流体储罐 |
| 化学品管道 | 高级控制电路 | 化学品管道 |

输入槽装 8,000 mB，两只输出槽各装 2,000 mB。第一、第二流体出口默认位于机器相对左、右侧，可在面板分别调整。另有一个固体输出槽、四个升级槽。转子在加工时加速，暂停时减速停在当前位置。

转子三根管依次显示输入、第一输出、第二输出。客户端按槽内流体 ID 查询方块顶面贴图，再用 `GetTextureAtlasUV` 取得它在地形图集 `atlas.terrain` 中的位置。每根管只采样对应图块，16×16 的流体动画帧由地形图集更新。具有顶面图块的新流体会自动显示。空槽或查不到图块时，管子呈淡蓝色，透明度为 64/255。

## 实机验证

小批次改动后已在游戏内核对全部 14 条配方，单批流体总输出最高为 400 mB。N2 出口已有 1,601 mB 时暂停，抽走 1 mB 后恰好产至 2,000 mB。N3 第一批产水 400 mB，第二批遇到固体出口堵塞时保留原料与电量。重新加载机器实例并腾空固体出口后，两批合计产水 800 mB、氯化钙粉 1 份，消耗 25,600 RF 和 400 RF热。

在网易开发环境中，14 条配方均已在放置的机器上逐批通过输入、各路产物、满速电耗与工艺热耗检查。逐个堵住配方使用的出口后，机器保留原料与电量。拆批前，N3 用底部导热块实测，降温后暂停，恢复供热后产出 1 氯化钙粉和 800 mB 水；该批实际扣电 25,600 RF。

P1 断电时剩余 150 tick，重进后保留进度、两路产物和剩余原料，补入 19,200 RF 后完成该批。已核对四个放置朝向。挖掉任一层都会拆除整机。上层自身没有掉落物，下层掉出一台机体和实际库存，含升级卡。上下层均可打开同一个下层面板；机内配方查询可翻页，两路流体出口可进入分面配置。

已在客户端采样确认转子平滑启停、三根管独立选材及清槽回退。此次使用单客户端，跨玩家同时观察尚待联机验收。
