# 蒸馏塔兼容小型蒸馏仓配方

蒸馏塔配方表加载时，自动为小型蒸馏仓表中的每条配方生成八倍吞吐的兼容配方，排在原生分馏配方之后。修改或新增小型蒸馏仓表内的配方后，重新加载两端即可生效；不包含加载完成后的动态注册同步。

两机共用温度计算：低于或等于最低温度不工作，达到最适温度后产出保持满速，偏高温度增加进料消耗，超过最高温度参数后进料倍率封顶。蒸馏塔仍每 tick 重新选配方，不复用小型仓的配方锁定状态。

进料、产出和加工耗热均乘 8，配方时长与单位产物耗热不变。缺料或缺热按蒸馏塔规则降速，输出堵塞则暂停。预热和散热不计入八倍加工耗热。结构仍要求至少两个输出口，兼容配方仅使用最高有效输出口，其余输出口库存不影响该配方。

## 游戏内验收（待执行）

- MiniJEI 和 MEI 中确认原生树脂配方及四条兼容配方均可见，可按输入、输出搜索；兼容配方仅一个产物，提示八倍倍率。
- 维持 393 K、供料供热充足时，每 200 tick 消耗 160 mB 蒸馏水、生成 1600 mB 蒸汽、消耗 3200 RF 热；小型仓对应为 20、200、400。蒸汽从最高口输出。
- 最适温度下，水配方每 tick 为 400 mB 输入、360 mB 输出、28800 RF 热；原油为 40、32、1280；植物油为 40、16、640。高耗热配方需保证持续供热足够。
- 比较最低温度、低温中点、最适温度、最高温度及以上的两机加工倍率；最高温度以上测试小型仓时先让它锁定配方。
- 堵塞最高输出口或放入不兼容流体，确认不扣料、不扣加工热；堵塞闲置口不影响生产。缺料和缺热时确认按比例降速。
- 切换输入流体、卸载区块、保存重进后确认正确选方与库存持久化；复查原生树脂分馏的产物及耗热不变。
