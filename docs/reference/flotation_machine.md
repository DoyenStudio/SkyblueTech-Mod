# 浮选机

方块 ID：`skybluetech:flotation_machine`。按 [矿物处理设计](../../dev_todos/ore_processing.md) 第三、八、十二节实现公共五倍线的 OP1 前处理，使用既有 `geometry.skybluetech.flotation_machine` 模型及 `flotation_machine_texture`／`flotation_machine_active_texture` 材质。

## 容量与槽位

| 类型 | 槽号 | 内容／容量 |
| --- | --- | --- |
| 物品输入 | 0 | 一种白名单粗矿 |
| 物品输出 | 1 | 对应预选矿料 |
| 物品输出 | 2 | 对应含金属精矿滤饼 |
| 升级 | 3–6 | 沿用 Processor 的速度、能效、自动弹出升级 |
| 流体输入 | 0 | 复配矿物捕收剂，8,000 mB |
| 流体输入 | 1 | 普通水，8,000 mB |
| 流体输出 | 2 | 含捕收剂浮选废水，8,000 mB |

基础储电 32,000 RF。两种流体按各自槽位匹配，支持既有桶／试管、流体管道与物品管道交互；原版漏斗禁用。界面提供物品端口和流体端口设置；废水只有一个输出槽，沿用默认流体输出，无需独立输出设置页。自动弹出升级只沿用框架能力，不提供回流优先规则。

## 工艺与制造

十种入口为原版粗铁、粗铜、粗金和本模组粗铝、粗锡、粗铅、粗银、粗镍、粗铂、粗钛，各登记一条精确 ID 配方，不接受矿石块、铀、粉末、锭、预选矿料或滤饼。

每批：**1 粗矿＋200 mB 复配矿物捕收剂＋200 mB 水 → 1 对应预选矿料＋1 对应精矿滤饼＋300 mB 含捕收剂浮选废水**。基准电耗 128 RF/t，200 tick，共 25,600 RF；无外接热或压缩空气消耗。

复用 Processor 的开批及结算检查，两只固体出口与废水出口必须同时容得下一批。堵塞和断电保留进度；原料在成功结算时整批扣除，产物同时结算。进度、流体库存及能源沿用现有方块实体保存。

机件加工台制造需要殷钢扳手、殷钢钳及 16 次加工；电动机件加工台继承同一配方。九宫格如下：

| 左 | 中 | 右 |
| --- | --- | --- |
| 钢板 | 电动马达 | 钢板 |
| 钢制流体储罐 | 机器框架 | 化学品管道 |
| 空气压缩单元 | 高级控制电路 | 钢制流体储罐 |

本次仅实现浮选机自身及 OP1；捕收剂供应、滤饼细磨／提取和工业分离机 P1–P3 不在本次改动范围，废水不自动销毁或回用。
