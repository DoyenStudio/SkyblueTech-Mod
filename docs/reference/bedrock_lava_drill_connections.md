# 基岩熔岩钻连接纹理

框架、控制器、能量接口和流体接口互相连接，与电池仓及其他方块不连接。连接只查询六个直接邻居，不要求结构组装完成，也不查询对角块。

## 贴图与角规则

`resource_pack/textures/blocks/multi_block_structure/bedrock_lava_drill/` 内 7 张 PNG 已去掉文件名的 `bedrock_lava_drill_` 前缀，原有材质 identifier 不变。公共无边框图注册为 `skybluetech:bedrock_lava_drill_frame_edgeless`。所有 PNG 内容保持原样。

贴图均为 16×16，外框宽两像素。每面拆成中心、四条边、四个角及四颗独立螺丝，按各面切平面内的直邻连接状态选取 UV：

| 角的水平邻边 | 角的垂直邻边 | 角区域 | 深蓝螺丝 |
| --- | --- | --- | --- |
| 未连接 | 未连接 | 原图角 | 显示 |
| 已连接 | 未连接 | 延续水平直边框 | 隐藏 |
| 未连接 | 已连接 | 延续垂直直边框 | 隐藏 |
| 已连接 | 已连接 | 公共无边框基底 | 隐藏 |

螺丝位于 `(2,2)`、`(13,2)`、`(2,13)`、`(13,13)`，颜色 RGBA 为 `(30,43,80,255)`。中心挖出四个 1×1 螺丝孔，由对应角的条件控制；隐藏时取 `frame_edgeless` 同位置底色，不叠加遮盖面。两个直邻均连接但缺少对角方块时，也不补螺丝或内角。

孤立方块采样完整有框图。有连接时，框架和控制器侧面中心使用 `frame_edgeless`；控制器前面板、激活面板及两个接口的中心保持各自原图。原图与基底的像素比较已确认该分工适用。

## 状态与资源生成

沿用 `server/misc/battery_matrix_connections.py` 的放置、移除、邻块变化和区块事件，以及六个 `skybluetech:connection_*` 布尔状态。两类机器共享延迟更新队列和已加载位置索引，按当前方块所属集合判断连接，不互相连接。只在值变化时更新，保留朝向及 active；不可读取邻块时不清空原有连接状态。

控制器保留 `y_rotation_offset: 180` 和原有四向旋转，世界模型正面为 north，物品栏完整方块的可见 south 面使用前面板。方向条件采用显式括号，兼容 manifest 的 Molang 1.18.0 语义。

四种外壳使用格式版本 `1.21.90` 以支持既有 `culling_layer` 模式；同类机器共用剔除层，电池仓另用自己的层。每个模型 62 个可见性骨骼组、276 个备选单面片，每种状态实际覆盖每面 15 个不重叠区域。

```powershell
node tools/generate_bedrock_lava_drill_connections.cjs
node tools/validate_multiblock_connections.cjs
```

生成器与电池仓共用 `tools/lib/generate_multiblock_connections.cjs`，修改分区或条件应修改该源文件，再执行两个机器各自的生成入口。重新生成电池仓不改变现有资源。工具只处理 JSON，不执行模组 Python。

## 验收范围

静态验证枚举每种机器 448 组连接/朝向场景，核对逐像素覆盖、边角及螺丝采样、旋转映射、材质和剔除引用；不能代替目标客户端视觉验收。

本次开发客户端已重载附加包，确认新分组脚本加载正常，现有 78 个电池仓外壳六向状态与实际邻块一致。临时放置的钻机四类外壳通过混合 2×2 连接及拆除一个角后的 L 形状态检查，截图可见相连面边框消失并保留面板；测试方块已清理。全部四朝向/激活态视觉、跨区块和存档重进仍需完整验收。

游戏内检查孤立、直线、L 形、2×2、缺对角、竖直连接、四朝向控制器及 active、物品栏前面板，再检查拆放、快速重放、跨区块及存档重载。框架新增无 tick 的方块实体供加载事件枚举；旧存档中原无方块实体的框架是否补建仍需验证，必要时重新放置旧框架。
