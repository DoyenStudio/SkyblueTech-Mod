# 导热块

方块 ID：`skybluetech:heat_conductor`，创造栏位于热力机械组。
工作台使用八个铜板围绕一个铁锭合成四个导热块。

每块独立储热，继承 `HeatCtrl`，六面均允许热输入和输出，自身不产热、不耗电。
热量只流向低温邻居，仍检查机器的供热面和受热面；多方块经供热口、受热口连接。
初始温度为环境温度，断热后保留余热并逐渐与环境换热，沿用机器热量存档。

参数：热容 1 RF/K，同材质接触热导 0.5 RF/(tick·K)，环境换热系数 0.0002 RF/(tick·K)。
每五 tick 沿现有 `HeatCtrl` 路径结算，异材质接触热导取两端热导的调和平均；普通热机
默认热导仍为 0.1，普通机器之间保持原行为。每次交换立即写回并限制到两端等温，
避免分叉多次使用旧热量。此版本沿用顺序交换，长链传播与分支分配仍有更新顺序偏差。

## 连接纹理

`heat_conductor.png`、`heat_conductor_edgeless.png`，像素不变；原备份文件保留。
16×16 贴图按四像素外框分区，中心为 8×8，四角为 4×4，没有独立螺丝区域。
只与同类导热块连接，沿用六邻居事件、区块加载索引和拆除后延迟刷新。
连接边采样无边框图，外轮廓保留边框，单边连接角延续剩余直边；不查询对角。
物品栏始终展示完整有框方块，内部面使用独立剔除层。

生成：`node tools/generate_heat_conductor_connections.cjs`
静态验收：`node tools/validate_multiblock_connections.cjs`

## 游戏内验收（待执行）

- 供热机允许的供热面 → 1/4/16 个导热块 → 需热机受热面，检查预热及持续供热。
- 接错机器面不传热；分叉、环形、多个热源时不凭空产热，低温端不向高温端送热。
- 移除热源后余热继续供热；拆放、跨区块加载及退出重进后温度和连接正确。
- 单块、横纵直线、L 形、2×2、缺对角、上下连接，检查六面无接缝和外框保留。
- 确认不与电池仓等外壳连接，机器接触处不消去导热块边框；物品栏有完整边框。
- 验证配方、译名、创造栏及挖掘掉落。
